# Computer fundamentals, step by step

Reconstructed draft — review before submission.

## 1 · Start with familiar technology

Name everyday uses of computers and distinguish input, processing, output, and storage. Learners trace a simple action such as typing and saving a note.

## 2 · Identify the components

Introduce the keyboard, mouse, monitor, processor, memory, and storage. Sort component cards by function, then explain how they work together.

## 3 · Separate hardware and software

Compare physical parts with the instructions they run. Distinguish the operating system from applications using familiar examples.

## 4 · Practice operating-system skills

Open an application, create a folder, save a file with a meaningful name, locate it again, and close the application safely.

## 5 · Apply and explain

Complete a small task: create and save a document, identify the devices involved, and describe its input–process–output–storage path. Use a checklist and an explanation to assess understanding.

## Why this order

The sequence moves from familiar experiences to concepts, then guided operations and independent application. Each step supplies knowledge needed by the next.
