# An instructional material you can try

Reconstructed draft — review before submission.

## Outcome and format

Digital, with a printable alternative. By the end of a 15-minute lesson, a beginner will retrieve values from a five-element array correctly in at least four of five practice items.

## Plan the interaction

Warm up with five numbered slots. Reveal that code labels the first slot 0. Select slots to inspect their values, then answer index questions. Give explanatory feedback and allow another attempt.

## Alignment and appropriateness

Every example and quiz item targets index-to-value mapping. Small arrays, everyday items, and a worked example reduce unnecessary complexity for beginners.

## Access and creativity

Use text labels alongside colors, keyboard-operable buttons, readable contrast, and no time limit on quiz responses. The numbered-slot model makes invisible memory organization visible. A paper version can use labeled cards.
